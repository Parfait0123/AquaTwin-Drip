# AquaTwin·Drip — Jumeau numérique pour l'irrigation goutte-à-goutte

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**AquaTwin·Drip** couple un solveur physique 2D (équation de Richards) avec AquaCrop et une IA frugale (Random Forest) pour optimiser l'irrigation goutte-à-goutte en contexte de données limitées.
